# MLOps CLI Tool

CLI tool for managing mlops projects - add datasets, models, and more.

## Installation

```bash
pip install -e .
```

## Usage

### Add a New Dataset to a Project

```bash
mlops-cli add-dataset /path/to/project --dataset-name my_dataset
```

### Add a New Model to a Project

```bash
mlops-cli add-model /path/to/project --model-name my_model
```
